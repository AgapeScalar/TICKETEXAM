
- Простий трекер заявок з можливістю створення тикетів, збереження у базі даних (SQL Server) та відправки повідомлення в AWS SQS.
- Додано можливість прикріплювати файл до тикету — файл зберігається в Amazon S3, а посилання на нього зберігається у записі тикету.

Використані AWS сервіси

- Amazon SQS — черга повідомлень для нотифікацій про нові тикети
- Amazon RDS (SQL Server) — база даних для збереження тикетів
- Amazon S3 — зберігання прикріплень
